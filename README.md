# Rechte der Natur – Webplattform

Technischer Grundstand für die neue gemeinsame Rechte-der-Natur-Webplattform.

## Governance

- `gibdernaturrecht.muc-mib.de` bleibt eine getrennte WordPress-Referenzschicht und wird hier nicht technisch gespiegelt.
- `systemische-rechtsentwicklung.de` bleibt ein eigenständiges GitHub-/Vercel-Projekt.
- Diese Codebasis ist für die neuen Domains `rechtedernatur.de`, `rechtedernatur.bayern`, `dubistdieer.de` und `ichbindieer.de` vorgesehen.
- Produktive Domains werden erst nach Preview-, Inhalts-, Routing- und Referenzprüfung verbunden.
- `main` dient als kontrollierter Grundstand; Entwicklung erfolgt zunächst auf Preview-Branches.
